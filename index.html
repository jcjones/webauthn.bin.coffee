This is the Level 1 attestation mode checker. It's a work-in-progress. Code is on GitHub, and the master branch is deployed to abuljko.github.io/webauthn.bin.coffee.

You can open this page inside an iframe for testing as well.

To use this to test Web Authentication support in Firefox, be sure you're using Firefox 60 or later.
